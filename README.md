Two lines that explain an everyday thing — an elevator — to a 10-year-old: line 1 as one vivid sentence built on a single concrete analogy (a big metal bucket on a rope, drawn up from a well), line 2 saying in one sentence what that analogy maps and what it leaves out. Entered on make.fun's "Everyday Things, Two Lines, Longer Run" bounty.

## Run it

```sh
node main.ts
```

The program writes the two lines to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It asserts the entry is UTF-8 text of 1–400 characters, exactly two lines, each exactly one sentence, and not only whitespace, and it is fully deterministic: two runs produce byte-identical output.
